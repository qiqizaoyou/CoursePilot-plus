# 随课 · CoursePilot-plus

Windows 11 桌面课程自动化工具。通过本地截图、Windows OCR、鼠标与键盘操作识别课程目录和页面，并提供 DeepSeek / 智谱 GLM 双模型测验审核。

当前版本：**v0.6.18** · C# / WPF · .NET Framework 4.8 · x64

## 下载与使用

从 [Releases](https://github.com/qiqizaoyou/CoursePilot-plus/releases) 下载便携 ZIP，解压后运行 `随课.exe`。

发布包及 SHA256 校验文件同时保存在 [releases/v0.6.18](releases/v0.6.18)。

1. 选择目标屏幕，优先使用默认布局。打开主课程目录顶部，点击“确认并预检目录页”后手动切回课程窗口；随课不会自动最小化或在预检结束时抢回前台。目录预检通过即可开始，无需先手动画出全部区域。
2. 测验功能需要自己的 DeepSeek 与智谱 GLM API Key；视频固定点击当前视频区域中心。进入课程/测验后再检查对应区域。
3. 正确页面连续 3 次区域匹配失败后，才提示只框选不适用的那一页；未加载、未切换或窗口遮挡不直接判作默认不适用。已有自定义可通过“使用已存自定义”恢复；恢复默认不会删除保存的区域。运行时按 **F8** 停止。
4. 仲裁未通过时可人工填写答案，再通过程序的人工确认按钮继续。

详细操作和版本记录见 [使用说明](使用说明.txt)。不同电脑的框选教程、只识别诊断以及交给本机 Codex 排查的提示见 [本机校准与兼容性指南](COMPATIBILITY.md)。

## 主要功能

- 识别目录完成状态与任务数量，处理视频任务并循环寻找后续课程。
- 支持单选、多选、判断和多空填空；进行交叉审核及 12 票仲裁，支持经确认的同义表达合并。
- 仲裁暂停后允许人工处理，恢复时保留人工答案。
- 自动提交测验，遇到未完成提示时执行一次漏题补查。
- 提交前连续三次确认滚动到底；短暂画面变化可恢复，最多九轮、45 秒，失败保留每轮判断及现场截图。
- 填空写入后和最终复核时复制实际文字逐字核对，保留下划线、符号、空白及大小写；实际文字不符最多纠正一次。
- 初次确认最多等待 15 秒，前台窗口连续 3 次稳定后截图；任务点识别排除邻近橙色文字，并显示候选框。
- 模型回包错误按阶段和原因记录脱敏诊断，格式错误最多重试一次；同义判断失败转入人工填答暂停。
- 本地诊断日志与失败现场预览。
- 视频播放期间，普通编号讲解不作为测验题型；只有测验组合证据出现在视频区域外，或伴随原任务点变化，并连续两次确认后才因页面切换暂停。
- 默认布局优先，目录预检即可启动；进入课程、测验后分别检查。自定义按页作为后备方式，支持保留旧配置和一键恢复默认。

目录中数字大于 1 的任务按当前规则仅在本地跳过，不会修改平台的完成记录。

## 从源码构建

需要 Windows 11 x64、Windows PowerShell 5.1、.NET Framework 4.8，以及 Windows OCR 所需的语言支持。项目直接调用系统自带 C# 编译器，无需 NuGet 包。

在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出位于 `dist\v0.6.18\`。源码和构建脚本使用 UTF-8；Windows PowerShell 脚本保留 BOM。

## 离线验证

内置自测使用模拟点击、键盘、剪贴板及模型接口。执行：

```powershell
$test = Start-Process -FilePath '.\dist\v0.6.18\随课.exe' `
  -ArgumentList @('--self-test', 'artifacts\self-test') `
  -WindowStyle Hidden -Wait -PassThru
Get-Content '.\artifacts\self-test\test-results.txt'
exit $test.ExitCode
```

v0.6.18 发布前通过 **685 项功能及原图回归 + 362 项校准兼容性检查**，共 1047 项。本版新增 65 项检查，覆盖默认布局直接准入、原故障目录截图回放、自定义保留、逐页检查、三次匹配失败、加载/遮挡分流、取消，以及实际预检按钮在正常/最大化窗口中的成功与失败路径。校准测试命令和覆盖矩阵见 [兼容性指南](COMPATIBILITY.md)。原图回放使用未公开的本地证据图片，公开仓库不含私人截图，因此上面命令的结果数可能不同。这些离线结果不代表已在朋友的电脑上完成真实课程端到端验证。

## 数据与配置

- API Key 由用户自行提供，使用 Windows DPAPI 按当前用户加密保存；仓库不含密钥。
- 启用模型答题时，题目文本或截图会发往对应模型服务，可能产生 API 费用。
- 截图、区域配置和运行记录存放在程序旁的 `data` 目录；请勿将自己的运行数据提交到公开仓库。
- 填空回读会临时使用剪贴板，程序会备份并尝试恢复原内容；无法备份、复制或恢复时暂停。
