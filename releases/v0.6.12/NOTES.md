随课 CoursePilot-plus 首次开源发布，采用 MIT License。

下载 `CoursePilot-v0.6.12-win-x64.zip`，解压后运行 `随课.exe`。适用于 Windows 11 x64，需要 .NET Framework 4.8。测验答题需自行配置 DeepSeek 和智谱 GLM API Key。

本版修复填空实际文字回读范围不足的问题：

- 所有填空在写入后及最终复核时，都复制输入框实际文字逐字核对。
- 保留下划线、括号、运算符、空白和大小写，避免 OCR 漏读导致误停。
- 复制成功但文字不符时最多纠正一次；复制失败或纠正后仍不符则暂停。
- 漏题补查保留已填写的真实原文；填空确认失败展示最新采集现场。

发布前通过 285 项针对性离线检查。保存原图使用 Windows OCR；点击、键盘、剪贴板及模型接口均使用模拟环境验证，未执行真实课程端到端验证。

ZIP 内仅包含程序、运行配置、使用说明和 MIT 许可证，不含 API Key、个人截图或运行记录。`SHA256SUMS.txt` 可用于核对 ZIP 完整性。
