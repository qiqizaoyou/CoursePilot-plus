# 随课 CoursePilot-plus v0.6.13

本版增加本机手动引导，解决换电脑后直接使用原区域配置的问题。

- 目录 2 个、课程 3 个、测验 2 个区域，共 7 个区域均需手动画框、查看截图预览并逐项确认。
- 保存本机屏幕、Windows DPI、课程窗口位置和尺寸；环境不符或尚未全部确认时不允许启动。
- 启动前只读预检目录；视频仍固定点击用户确认的视频区域中心，不搜索播放图标。
- 扩大目录圆点识别范围和尺寸适配，保留高分辨率小圆点细节，排除无课程名称的装饰图案和歧义状态列。
- 框选失败也自动保存局部诊断，另提供“只识别 / 导出诊断”。不操作课程、不调用模型，诊断不包含密钥。
- 小屏可滚动查看界面，停止按钮固定于底部。

完整解压 ZIP 后运行 `随课.exe`，先阅读包内 `COMPATIBILITY.md`。旧版配置需要重新确认；不要复制其他电脑的 `data` 文件夹作为已校准配置。浏览器页面缩放和侧栏变化需主动重新校准。

通过 189 项手动校准兼容性测试及 567 项原有功能和目录原图回归，共 756 项。合成分辨率/尺寸测试及原图 OCR 回放不能替代朋友电脑上的实际校准和课程验证。

便携包包含程序、运行配置、使用说明、兼容性指南和 MIT 许可证，不包含个人运行数据、截图、API Key 或已确认的区域配置。
