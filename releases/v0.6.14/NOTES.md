# 随课 CoursePilot-plus v0.6.14

修复视频播放过程中因课件文字误报“页面变为测验”而暂停的问题。旧规则把“2.计算实参”等普通编号讲解当作题型标签；本版将页面分类与题目 OCR 容错分开。

- 页面判断要求组合证据，单个标题或题型词不足以认定测验。
- 播放期间，习题内容仅位于用户框选的视频区域内且原任务点仍在时，继续监测视频。
- 疑似页面切换时等待 5 秒重新截图，连续两次确认后才暂停；不确认则继续监测原视频，复查可随时按 F8 中断。
- 诊断记录触发的 OCR 原文、坐标、所在区域和组合判断，并保存两次复查现场。
- 保留 7 个区域手动引导、固定视频区域中心点击、任务点变绿后直接返回、填空实际文字复制核对及原有测验审核流程。

完整解压 ZIP 后运行 `随课.exe`。从 v0.6.12 升级的用户须按包内 `COMPATIBILITY.md` 完成全部区域的本机确认。

通过 652 项功能及原图回归和 189 项校准兼容性检查，共 841 项。原故障截图已通过 Windows OCR 回放，识别结果为视频；新增回归覆盖视频内习题、短暂/间歇误识别、真实页面切换、复查中停止、屏幕变化及任务点丢失。测试使用模拟输入与模型，不操作真实课程；实际课程运行仍需用户验证。

便携包包含程序、运行配置、使用说明、兼容性指南和 MIT 许可证，不包含个人运行数据、截图、API Key 或已确认的区域配置。
