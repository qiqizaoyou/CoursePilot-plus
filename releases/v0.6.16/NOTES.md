# 随课 CoursePilot-plus v0.6.16

基于 v0.6.15 修复手动引导与页面选择没有关联的问题，保留七区域确认、测验页尾复查和之前的视频判断修复。

- “当前页面”统一控制“框选当前页”和“只识别 / 导出诊断”。选课程页只框选任务点、视频和返回课程三个区域，完成后返回主界面。
- “继续未完成引导”按目录、课程、测验顺序补齐未确认组，自动跳过已经确认的组。
- 快捷按钮同步所选页面；提示、框选窗口及确认预览对应实际页面，主界面不再残留上一次诊断的目录预览。
- 取消保留已有配置；相同环境重画一页保留其他组，环境变化后重新确认失效组。全部七个区域仍需确认并通过预检。

升级：解压后运行随课.exe。可保留自己的 data 文件夹；同一台电脑及相同窗口布局的 v0.6.13–v0.6.15 已确认配置可继续使用。不要共享包含密钥及截图的 data 文件夹。

验证：685 项功能及原图回归、239 项校准兼容性检查全部通过，共 924 项。使用模拟桌面操作、模拟模型和离屏窗口；未操作真实课程。真实课程由用户验证。
