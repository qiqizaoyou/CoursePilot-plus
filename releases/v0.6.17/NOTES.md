# 随课 CoursePilot-plus v0.6.17

本版基于 v0.6.16，修复初次确认容易因窗口切换时机失败、任务点旁橙色文字被误判，以及同义判断回包失败被笼统显示为“回复为空”的问题。

- **初次确认更稳定**：最小化后先留 3 秒切换时间，含初始等待最多 15 秒；同一前台窗口连续 3 次稳定才截图。日志显示实际前台及未通过原因，正常预检继续核对已校准的屏幕与窗口环境。重新手动校准允许更换屏幕或程序。
- **任务圆点识别**：增加圆形轮廓检查，排除邻近橙色文字。预览绿框为有效圆点，红框为排除的候选；多个真实圆点仍要求重新框选。原始诊断图与候选标注图分别保存。
- **模型错误可定位**：分别报告最终正文为空、输出截断、JSON 错误和缺失字段，并记录发生阶段、结束原因、正文及推理长度。错误诊断保存到 `data/model-diagnostics`，不保存请求图片、请求头、API Key 或推理正文；最终正文片段经过密钥过滤。
- **同义判断可恢复**：给出完整合法 JSON 示例，格式错误最多重试一次；重试不增加票数。两家模型仍须共同确认同义，不直接忽略大小写、符号或有意义的空格。四步审批后的同义判断仍失败时，保留已完成进度并进入人工填答暂停，人工填写并确认后继续。

验证：685 项功能及原图回归、297 项校准兼容性与恢复检查全部通过，共 982 项，其中 58 项为本版新增。使用模拟桌面、模拟模型及本地图片，未调用付费模型接口或操作真实课程。实际课程由用户验证。

下载并完整解压 `CoursePilot-v0.6.17-win-x64.zip` 后运行 `随课.exe`。不要在压缩包预览或临时解压目录中直接运行，以便稳定保留旁边的 `data` 配置和诊断记录。配置仍保存在本机；发行包不包含个人配置、密钥或课程截图。
