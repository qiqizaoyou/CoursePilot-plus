v0.6.15 修复答完末题后无法确认页尾

- F8 可中断等待和复查；持续变化、超时或屏幕尺寸改变仍暂停。保留 v0.6.14 视频页面判断修复和全部 7 个区域的手动确认。

v0.6.12 所有填空均复制实际文字核对
- 每空写入后和最终复核时，均重新定位输入框，选中并复制实际文字；不再只在 OCR 发现大小写差异时触发。
- 实际文字与已审核答案逐字比较，保留下划线、括号、运算符、空格、换行和大小写。OCR 只供定位与诊断，不决定已写入文字是否正确。
- 复制成功但实际文字不符时，每题每空最多按原答案纠正一次，再复制核对；复制失败或纠正后仍不符则暂停，不连续改写。
- 保留原剪贴板备份与恢复机制；日志明确显示复制核对开始、预期文字、实际文字及核对结果。
- 漏题补查时，已填空先读取真实原文并保留，不把 OCR 误读结果当作原答案。
- 填空确认失败时显示最新采集现场，保存 fill-text 诊断截图与原因。

- 已选中则直接继续；暂时无法定位时最多重新截图复查两次，不因 OCR 漏读而重复点击。题面、选项文字或布局变化及识别冲突仍暂停。
- 选项识别或确认失败时显示最新现场截图，保存选项坐标、选中状态、OCR 结果及失败原因，避免只显示点击前预览。
- 保留填空大小写实际文本回读、人工仲裁暂停、1/8 屏查题、目录规则及固定视频区域中心点击。

- 点击后窗口最小化，等待 3 秒；请保持原测验中该题题干可见。程序用新截图核对同一道题和位置，成功后记为“人工确认完成”，直接跳过该题，不重新获取或审核答案。重复点击只生效一次。
- 若未看到同题题干、题量或可见测验标题不符、布局变化，继续暂停；回到原题并恢复原缩放后可再次确认。确认操作以用户填写结果为准，不自动判断人工答案是否正确。
- 后续漏题补查时，人工题已有答案便跳过；仍为空则再次等待人工补填，不重新调用模型。其余题目、1/8 屏下滑、提交及返回课程循环沿用原规则。
- F8、停止按钮、关闭窗口仍会结束任务，不能再点继续；其他识别故障保留原有处理方式。本次暂停进度仅保留于当前运行中，不支持关闭程序后恢复。

v0.6.0 测验自动提交、漏题补查一次与课程循环
- 连续三次下滑无位移、当前可见题目已处理并识别到底部提交按钮后，点击底部提交，等待 5 秒。
- 优先识别“未做完/未完成/未作答”等警告，不限制题型。首次警告点击取消并确认弹窗关闭，再上滑到顶（连续三次无位移）。
- 从顶部重新逐题读取实际作答状态：选择题有勾选、填空所有空非空即可跳过，不再获取已答题答案。
- 漏题优先复用本次已审核答案；没有缓存才走原四步审核及 12 票仲裁。部分填空只补空白处，保留已有文字。
- 补查仅一次。第二次提交仍提示未做完时停止，保留弹窗，不强行提交。
- 弹窗正文仅为“确认提交”时才点击其中的提交；等待 3 秒，核对结果页与返回课程按钮后返回，再沿用原有 10 秒目录加载及查找下一课程循环。
- Windows OCR 漏读蓝色按钮上的白字时，仅对实际按钮区域做局部复读。弹窗或结果无法确认时停止并保存诊断，不重复正式提交。
- F8 可中断滚动、等待、补查、提交和返回。自动提交取代旧版本的“停在提交前人工检查”；以下版本记录仅说明历史行为。

- 找不到合适空白位置时停止并提示人工移开焦点；失焦后仍有真实文字差异，继续执行原有局部复核及停止规则。

- 异常停止及 F8 停止时，底部预览说明同步改为“已停止”及原因，保留模型审批结果。
- 新增 2026-11-07 现场光标截图的 Windows OCR 离线回放，以及真实竖线、额外竖线和取消回归。

v0.5.0 双模型审核、同义一致与 12 票仲裁
- 每题先执行 DeepSeek 初答 → GLM 审批 → GLM 独立作答 → DeepSeek 审批，最终裁决后再操作页面。
- 两次审批通过且答案一致时采用。同义不同说法也算一致，填空文字不同时由两家分别确认含义等价。
- 任一审批否决、无法确认或答案分歧时，保留两份初答，再取两家各 5 份独立作答，总计 12 票。
- 最高票至少达到第二高票的 2 倍才采用；8:4、6:3:3 通过，7:5 停止。12 票一致直接采用。
- 多选按完整集合，多空按完整答案向量计票。同义须双方确认且关系无冲突才合并；都能答对不等于同义。
- 写入后的预览及时更新；整题回读不同先重截、局部放大复核，连续不一致才停止，并保存实际截图及 OCR 读数。
- 右上角显示两份初答、两次审批、仲裁进度及最终候选票数；停止时保留结果。
- 以下旧版记录只说明历史变动，当前测验决策规则以 v0.5.0 为准。

DeepSeek + 智谱 GLM 章节测验
1. 完整解压后运行“随课.exe”，分别打开左侧“DeepSeek 设置”和“智谱 GLM 设置”。
2. 每位使用者输入自己的两家 API Key，可分别选择“在本机记住密钥”。GLM Key 来自 bigmodel.cn。
   DeepSeek 模型 ID 为 deepseek-flash；GLM 默认 glm-4.6v，可改为账户支持的视觉模型。
   GLM 连接测试发送内置测试图片，验证所选模型能接受图片请求，可能产生少量费用。
   未配置两家 Key 时，测验会在模型创建阶段停止；视频流程不要求 Key。
3. 打开一份章节测验，点击“测验区域”，依次框选：
   - 含“章节测验”标题和任务黄点的区域（参考图红框范围）。
   - 整个题目内容视口，从正文顶部到任务栏上方，包含题卡，避开右侧目录、桌宠和浮动提示。
     请框选整个滚动视口，不要只框当前一道题。区域按本机屏幕比例保存；改变缩放后需重新框选。
4. 全部七个区域均确认后，手动回到课程目录顶部，使用“确认并预检目录页”→“确定开始刷课挂机”启动。
   软件进入课程并等待5秒加载后，先识别测验，再执行原有视频流程。
5. 测验标题与至少一个任务黄点同时出现时进入做题模式，黄点数量不限。
   读取题量，按题号和题型划分题块。题干、选项或输入框不全时继续按约1/8屏下滑并拼接。
6. 单选、多选、判断题执行四步交叉审核，必要时进入 12 票仲裁：
   - 带字母题使用大写字母，无字母判断题使用“对”或“错”。多选的 AC 与 CA 视为一致，不逐字母拼接答案。
   - GLM 的独立作答只接收原题。两次审批分别只接收原题及待审答案，不提供其他审批或票数。
   - 先完成最终裁决，再操作页面；仲裁请求使用全新上下文，不携带此前答案或票数。
   - 本地重新定位选项圆圈中心并点击，等待1秒截图，确认选中状态。
     字母漏读时先补读或核对已确认的同题选项身份，最多重新截图复查两次；已选中不会再点。
     漏点时最多补点一次；多选题仅调整尚未达到预期的选项，防止重复点击导致取消。
   - 本地截图确认实际选项与裁决结果一致后，先在当前画面查找下一题。题目不完整才下滑约 1/8 屏补图。
7. 填空题同样执行四步审核与必要的仲裁。不同文字先进行全半角、首尾空白等归一，再由两家确认同义。
   每一空都按编号对应且同义才算整份一致；例如“顺序结构/顺序控制结构”可等价，“顺序结构/循环结构”分开。
   仲裁胜出后选择组内真实返回过的一份完整答案填写，不组合不同候选。审核否决不再触发“填更正后立即停止”。
   每空填入后等待1秒截图，并复制输入框实际文字逐字核对；最终复核时再次复制核对。复制成功但实际文字不符时每题每空最多纠正一次；复制失败或纠正后仍不符时暂停，并显示最新现场。
   模型仍可能共同犯错；交叉审核与多数票都不保证答案完全正确。
   正常无重试时四步共4次请求；仲裁增加10次独立作答，共14次，其中12份答案计票。
   填空同义判定每阶段按需额外调用两家各一次，不增加票数。请求重试不会生成额外票位。
8. 到底连续确认三次且识别到提交按钮后，软件自动提交；平台提示漏题时取消并从顶部补查一次。
   再次提示漏题即停止。只有普通确认弹窗才正式提交，提交成功后返回课程并继续寻找下一课程。
   本轮补查只检查是否已作答，不重复评判已有答案是否正确；多选题有勾选即视为已作答。
   API 异常或手动停止时保留页面已选状态；重新开始会重新识别、复核，不直接信任旧选项。
9. F8 在网络等待、滚动、点击确认期间均可停止。停止后不执行迟到的模型结果。
   HTTP 连接/超时/限流最多尝试3次。回包字段异常、无效或截断的 JSON 最多重新请求一次。
   单次请求超时90秒；重试耗尽、密钥无效、余额不足、收不齐12份有效答案或未达票数门槛时停止。
10. 文字识别使用 Windows 自带中文 OCR，无需安装 Python 或 Node。
    设置窗口显示 OCR 是否可用；若缺失，请在 Windows 中文语言选项安装“光学字符识别”。
    操作期间保持页面无遮挡，不手动滚动或切换目标页面。

分发与密钥
- 发布包只包含程序、运行配置和本说明，不包含任何个人密钥与运行数据。
- 密钥通过 Windows 当前用户 DPAPI 加密保存到：
  %LOCALAPPDATA%\CoursePilot\deepseek.key
  %LOCALAPPDATA%\CoursePilot\glm.key
  勾选本机记住后才保存；取消记住仅用于本次进程；“清除密钥”删除本机保存并清除当前会话 Key。
- 密钥不写入 EXE、程序旁的配置或日志。分发完整发布压缩包即可，每人自行配置自己的 Key。
- 题图使用 HTTPS 直连 api.deepseek.com 与 open.bigmodel.cn，只发送当前题的必要图块，不上传整屏或右侧目录。
  题图可能包含题目自身的水印等内容，请自行检查框选区域。
- 程序仍在旁边的 data 目录保存最近截图和运行日志；分发时不要带上个人 data 目录。

使用方法
1. 将整个便携包解压到可写目录，双击“随课.exe”。不需要安装 Python 或 Node。
2. 在学习通打开目标课程的主章节目录顶部。先确定本机窗口大小、位置和页面缩放，校准及运行期间保持一致。
3. 在随课中选择目标屏幕和“当前页面”，点击“框选当前页”设置所选页面；或点击“继续未完成引导”补齐未确认组。默认区域仅供参考，不能直接开始。
   先手动框选完整章节目录（区域1），再框选顶部完成状态点附近（区域2）。Esc 可取消。
   区域1包含状态点及右侧课程名称，无需放在左侧18%内；避开导航、悬浮助手和第二列无关状态点。
   区域2应包含顶部整体状态圆点；不要框入其他有色图标。
   然后手动打开一节课程，点击“课程页区域”，依次框选：
   - 区域1：仅任务圆点，保留少量白边，避免框入“任务点”文字。
   - 区域2：完整视频画面。
   - 区域4：“返回课程”的中文文字，避免只框到返回箭头。
   然后手动打开测验顶部，框选标题任务点区和完整题目内容视口，共完成七个区域。
   每组查看预览，逐项勾选“我已核对”，识别通过后保存。视频预览红十字是固定点击位置。
4. 手动回到主课程目录顶部，点击“确认并预检目录页”，通过后再点击“确定开始刷课挂机”。
5. 程序最小化，倒计时3秒后截图。请在倒计时内切回目标课程目录页。
6. 优先从上到下检查目录课程的状态点，允许出现多个黄点、绿点。
   绿点跳过；黄点先读取圆点内数字，0 和 1 点击其右侧课程名称进入；大于 1 本轮记为已处理并跳过。
   已识别到课程黄点时，不会因顶部区域没有圆点或有多个圆点而中止。
   顶部整体状态为绿点时也继续向下查找，不再据此提前结束。
   当前可见课程全部为绿点或本次已跳过时，在区域1中间向下滚动约1/4页，再次检查。
   只有实际下滑前后的两张截图在课程列表比对区逐像素相同，才判定目录已到底。
   两次截图包含一次实际下滑并留出稳定时间，间隔不超过2秒；超时则继续确认。
   比对区为区域1与整屏上方4/5的交集，排除屏幕底部1/5的桌宠。
   滚动后若发现可处理黄点，优先进入该节，完整目录仍用于查找黄点。
7. 运行中按 F8 或点击悬浮窗的“停止”即可中止。
   手动重新运行需两步确认；自动切换课程时无需再次确认。

课程页自动流程
- 目录黄点 0：点击进入后停留5秒，直接返回目录；本轮记录已处理，不调用视频或测验流程。
- 目录黄点大于1：不进入该节，本轮记录已处理后继续查找下一节，平台状态保持原样。
- 目录黄点 1：进入课程后等待5秒，识别测验、视频、图文正文或明确的“暂无内容”。未知页面复查一次后仍无法确认则停止。
- 视频流程点击已保存的课程页区域2中心一次。无需识别播放图标，不向上归顶或下滑寻找按钮。
  任务点可从当前正文中识别，或使用已校准的课程页区域1；点击坐标始终由区域2决定。
- 任务点文字可见但状态不清晰，或播放中任务点消失时，等待5秒复查；仍无法确认就停止，保留页面，不能按完成处理。
  复查保持页面位置不变。只有明确识别到“暂无内容”等空内容提示才允许跳过该节。
- 点击播放后第10、20、30秒，比较已保存的课程页区域2内三张截图的RGB像素。
  任意一张存在变化即判为播放成功；三张完全相同则判为播放失败。
  区域2以外的变化不计入播放判定。
- 播放失败时点击区域4“返回课程”，等待5秒，再从目录重新查找并重试。
- 从点击播放起，每5秒检查当前任务点：黄点继续等待，绿点表示当前任务完成，无需等满三次视频截图。
  目录数字1的视频任务变绿后立即点击区域4返回目录，不再下滑查找其他任务，等待10秒再查找下一节。
  若进入后已明确看到唯一视频任务点为绿点，也直接返回。测验沿用原有答题、仲裁、人工继续与提交流程。
- 识别故障时显示实际课程现场，并在 data/course-diagnostics 保存截图与原因，修正页面或识别范围后重新开始。
- 循环直到实际下滑确认目录已到底，或用户停止、状态无法明确识别。

识别约定
按已确认规则，静态讲义若30秒不变，也会判为播放失败并返回重试。
三帧比较只能反映画面是否变化，不能直接验证播放器的真实播放状态。
课程名称点击位置按参考截图中状态点与标题的相对布局推算。

识别与停止
黄点包含参考图中的橙黄色圆点，绿点包含带白色对勾的绿色圆点。
目录未识别到课程状态点时暂停。已取消80屏查找上限，持续查找直到确认目录已到底。
滚动停止判断采用精确RGB像素比较；比对范围内若持续有其他动画，会继续查找，可按F8停止。
无任务点课程的跳过记录按目录课程名称图像匹配，仅在本次运行中生效。
返回目录后即使该节仍为黄点，也会选择其他课程；手动重新开始时清空跳过记录。
“按完成处理”是本程序的跳过规则，不会直接改写平台记录；运行期间应保持页面布局一致。
滚动距离根据系统“每次滚动若干行”设置估算：课程目录约1/4页，章节测验查题约为目标屏幕高度的1/8。
系统设置为整页滚动或禁用滚轮时会暂停，请改为每次滚动若干行。
自动化期间请勿手动滚动、遮挡或切换目标页面；暂停后再调整。
F8 被其他程序占用时不会开始，避免失去快捷停止入口。
按普通权限运行即可；目标程序若以管理员身份运行，系统可能拒绝点击。

本地文件
程序旁的 data 文件夹保存：
- region-1.png、region-2.png：最近一次区域截图，每次覆盖。
- course-task.png、course-video.png：最近一次课程页任务点和视频截图。
- video-1.png、video-2.png、video-3.png：最近一节已采集的视频验证截图，逐张覆盖。
- regions.ini：目录页与课程页区域配置，兼容旧版只有目录区域的配置。
- run.log：运行记录。
程序不读取课程账号密码；识别到待处理测验时使用个人 Key 连接 DeepSeek 和智谱 GLM。
quiz-question.png 保存最近一次测验题块或选中状态预览。
quiz-decision.txt 保存最近一题的双模型审批与仲裁过程，run.log 保留跨题记录。
fill-readback 文件夹保存发生差异时的整题视口、局部输入框、OCR 读数及取得的实际文字，仅用于诊断。
其中带 option-ocr 的文件保存选项识别失败现场、坐标、选中状态与原因；窗口预览同步显示本次最新截图。
其中带 fill-text 的文件保存填空确认失败现场与原因；窗口预览同步显示最近采集的填答现场。
删除 data 文件夹可清除程序旁的截图、运行记录及区域配置。
